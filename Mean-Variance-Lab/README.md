# Mean-Variance Lab

Interactive browser-based Markowitz mean-variance teaching simulator.

The app shows the risky-asset efficient frontier, GMVP, asymptotes, tangency portfolio, Capital Market Line, target portfolio weights, and risk-free/tangency allocations.

## Numerical precision

When asset expected returns are close together, the target-return display automatically increases its decimal precision. This is important because small target-return changes can imply large changes in long/short portfolio weights.
